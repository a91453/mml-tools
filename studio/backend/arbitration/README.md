# Arbitration

Purpose: turn reported conflicts into explicit, reviewable decisions.

An arbitration record must identify:

- affected canonical event IDs;
- candidate action (keep / reject / move role / change octave / change duration / merge / split);
- status (`pending`, `accepted`, `rejected`);
- musical reason;
- supporting evidence IDs;
- whether the choice is source-faithful or a Mabinogi Mobile adaptation.

Decision order:

`source traceability`
→ `lead continuity`
→ `Core3 completeness`
→ `Mobile audibility / role clarity`
→ `minimal adaptation`
→ `theory/statistical cleanup last`

The arbitration layer is the only place allowed to convert a detected difference into a deliberate musical choice. The score importer and comparison layer must remain descriptive.
