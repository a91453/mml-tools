兩個世界：焦點決定鍵盤

工作坊有兩個可以動的地方——鋼琴捲軸與 MML 文字區——而它們共用鍵盤。規則只有一條：

焦點在 MML 文字區或其他輸入框（包括下拉選單）時，鋼琴捲軸與播放的快捷鍵都讓路，保留原生的文字操作：Ctrl+A 是全選文字、Ctrl+C 是複製文字、空白鍵就是打一個空格。

例外有三組：Ctrl+D 在目前音軌的 MML 文字區裡也會複製選取的音符（不會開瀏覽器的書籤；其他輸入框不攔截）；Ctrl+Z／Ctrl+Y／Ctrl+Shift+Z 在任何地方都是工作坊自己的復原與重做；Ctrl+S 在任何地方都交給工作坊的儲存（見整個工作坊通用）。

對話框、設定抽屜或右鍵選單開啟時，不會操作背後的音符。

捲軸那一側的鍵有一個共同前提：要有選取。Delete、+／-、Ctrl+C／X／D 都是對「選起來的那幾個音」動作，沒有選取就什麼都不會發生。

另外，對話框或右鍵選單開著的時候整組停手：力度框開著按 Delete 不會刪掉背後的音符，按 3 也不會偷偷換掉音符長度。

會改動音符的鍵在演奏中不作用（捲軸與文字區這時都是唯讀）；暫停中可以改，改動在按下繼續之後生效。

播放的那五顆鍵是另一組（Space 與四顆方向鍵）：它們不需要選取，但同樣在文字區打字時讓路。詳見播放控制。

播放控制

鍵作用前提
Space演奏／暫停／繼續（等於按「▶ 演奏」）音色庫已載入（「▶ 演奏」不是灰的）；焦點不在其他按鈕、輸入框或下拉選單上；沒有拖曳中的音符
←／→播放頭退／進一小節演奏中或暫停中
↑回到開始線；沒有設開始線就回到曲首演奏中或暫停中
↓停止演奏中或暫停中
媒體鍵：播放／暫停、停止、上一首／下一首（或快退／快轉）演奏／暫停、停止、播放頭退／進一小節按過一次演奏之後；鍵盤或耳機的媒體鍵要送到哪個分頁，由瀏覽器與作業系統決定

這五顆鍵按住不放不會連發，按著 Shift、Ctrl、Alt 時也不作用；對話框、設定抽屜或右鍵選單開著時同樣停手。

鋼琴捲軸的鍵盤

鍵作用前提
0切到只選取（箭頭）模式—
1 2 3 4 5 6切到繪製模式，音符長度：全音符／二分／四分／八分／十六分／三十二分（對應工具列上那六顆 1、2、4、8、16、32）—
7六十四分音符。工具列上沒有這一顆按鈕——按下去那六顆會全部暗掉，那不是壞掉，是「現在的長度不在這六顆裡」。左邊那個音符圖示會告訴你現在是什麼—
.切換接下來畫的音符帶不帶附點（長度變 1.5 倍）。點工具列上那個音符圖示也一樣。已經畫好的音要加附點走右鍵選單繪製模式；六十四分音符不支援附點
Ctrl+A選起目前這條音軌的全部音符。接著按 Ctrl+C 就是整條的 MML焦點不在輸入框；沒有拖曳中的音符
Ctrl+D選取的那一段複製接在自己後面，往後推整數個小節。按住 Ctrl 連點 D 就一段一段鋪出去有選取、非演奏中；焦點在捲軸或目前音軌的文字區
Delete／Backspace選起來的音變回同長度的休止符有選取、非演奏中
+／-力度加減一格（力度是 0–15，到頭就停）。數字鍵盤上的 + - 也可以有選取、非演奏中
Ctrl+C複製選起來的音（以 MML 文字放進剪貼簿）有選取；焦點不在輸入框
Ctrl+X剪下選起來的音（原處變成休止符）有選取、非演奏中
Ctrl+V把剪貼簿裡的 MML 片段貼成音符。落點依序是：選取的開頭、滑鼠所在的位置、播放開始線；三者都沒有就只提示一句非演奏中；焦點不在輸入框
Esc取消正在進行的拖曳並停掉試聽；沒有拖曳的時候清空選取清空選取時：焦點不在輸入框、沒有對話框開著

Ctrl+D 保留選取起點在小節內的位置，往後移整數個小節（夠放下整段選取的最少小節數）再貼上；不會把後面的內容推開。落點範圍內原有的音符會被覆蓋，完成時會回報覆蓋了幾個。每次都可用 Ctrl+Z 復原。新副本會自動選取，因此連按可繼續往後鋪排；按住不放不會連續觸發。Ctrl+V 也一樣是覆蓋、貼完自動選取剛貼上的音。

六十四分音符不能加附點，這跟 Canonical 規則的方向一致：64. 在 Final 裡是禁止的寫法（MOBILE_SYNTAX §4）。

拖曳中的微調鍵

下面這幾顆只在按住滑鼠拖曳音符時有用（包括剛按下去、還沒放開的新音符）。捲軸上方的提示列會寫出現在能用哪幾顆。

鍵作用前提
← →前後微調半格（六十四分音符的長度）搬動或改長度中
↑ ↓上下一個半音搬動中（改長度時沒有作用）
Shift+↑ ↓上下一個八度搬動中（改長度時沒有作用）
Shift+← →前後一小節。是位移不是吸附——落在反拍上的音會移到下一小節的同一個反拍搬動或改長度中

框選拖曳中按方向鍵不會有任何作用（也不會捲動頁面）。

滑鼠與滾輪

手勢作用前提
左鍵點空白處畫一個音（長度是目前選的音符長度）。按住不放可以先拖到想要的位置再放開繪製模式、非演奏中
左鍵點空白處清空選取並設播放開始線；演奏中只移動開始線只選取模式
左鍵空白處拖曳框選：選取變成剛好框到的那幾個（框到 0 個就是清空）只選取模式、非演奏中
Ctrl+空白處拖曳框選追加：已經選起來的留著只選取模式、非演奏中
右鍵點空白處開捲軸選單（前兩項就是設定演奏開始線／結束線，其他有段落標記、選前方／後方所有音符、貼上、插入／刪除小節）—
左鍵點小節尺設播放開始線演奏中也可以
右鍵點小節尺開小節尺選單（開始線、結束線、清除範圍播放、此位置加入力度、變拍）演奏中也可以
右鍵點捲軸左上角（小節尺左邊、琴鍵上方）開曲首拍號選單設定裡的「拍號顯示及調整」是啟用
左鍵點音符選它並發一聲（演奏中只選取、不發聲）—
右鍵點音符開音符選單（沒選起來的音會先被選起來）—
拖曳音符搬動。拖的是多選裡的其中一個音時，整組一起搬非演奏中
拖音符右邊框改長度拖的音不在多選之中、非演奏中
Ctrl+點音符加進／移出選取非演奏中
Shift+點音符範圍選取：從上一次點的那個音選到這個音非演奏中
雙擊音符MML 文字區的游標跳到這個音的後面只選取模式、非演奏中
點別軌的音符（捲軸上淡色的那些）切換到那一軌並選起這個音只選取模式；那一軌有顯示在捲軸上
點左側琴鍵試聽那個音演奏中也可以
點段落標記的膠囊捲軸捲到那個標記—
右鍵點段落標記的膠囊開標記選單（修改標記文字、移除這個標記）—
拖曳音軌分頁改變音軌順序（內容、樂器、靜音與顯示狀態一起搬）—
拖曳捲軸與樂譜區之間的分隔線調整兩邊的高度—
Ctrl+滾輪格寬縮放（以滑鼠位置為中心）—
Ctrl+Shift+滾輪　或　Alt+滾輪列高縮放—
Shift+滾輪水平捲動（瀏覽器本身的行為）—

Ctrl+點音符與 Ctrl+框不一樣，而且是刻意的。 點是切換（已經選起來的會被抽掉），框是純追加（已經選起來的一定留著）。框選很難精準地「只框到還沒選的那些」，所以它不做切換。

純框（不按 Ctrl）是取代：選取變成剛好框到的那幾個。選取可以在視窗外而畫面上沒有任何線索，所以預設不追加——不然「在第 3 小節選好幾個音、捲到第 40 小節再框住眼前這幾個」會默默改到第 3 小節。

整個工作坊通用

鍵作用前提
Ctrl+Z復原任何地方都作用，文字區裡也是工作坊自己的復原
Ctrl+Shift+Z／Ctrl+Y重做同上
Ctrl+S把這一份存進這個瀏覽器的歌曲庫。已經存過（或從歌曲庫開過）而且名字沒改的話就直接存回同一份；否則打開「儲存樂譜」框見下方說明
Esc關閉對話框、設定抽屜、窄畫面的選單（段落標記的輸入框請按取消）；WAV 或影片匯出進行中時不會關掉那個框—
↑ ↓調整捲軸與樂譜區的高度（Shift 一次跨大步）焦點在分隔線上

Ctrl+S 有兩種行為，分界是「這還是不是你上次存的那一份」。不論哪一種，瀏覽器自己的「另存網頁」都不會跳出來。

直接存回去——這次開啟頁面之後，你已經把這一份存進歌曲庫（或從歌曲庫開過一份），而且之後沒有改檔名。這時候按下去就直接寫回歌曲庫裡同名的那一份，不會再問一次要不要覆蓋，畫面上會出現一句確認。這是唯一一條不問就覆寫既有存檔的路，所以下面那幾種情況一律不走它。

打開「儲存樂譜」框——第一次存、重新整理頁面之後的第一次、改過檔名（那是另存新檔）。按「新增」、用剪貼簿「貼上」、從「檔案」匯入、或「從 Studio 開啟」之後也會打開框：那些都是把編輯器裡的東西整批換掉，換完之後它已經不是你原本那份檔案了。

這一份是空的（沒有任何音符）時按下去只會提醒一句，不會開框。已經有別的對話框開著時它不作用——除了「儲存樂譜」框自己開著的時候，那時 Ctrl+S 就等於按下那顆「儲存」（名字跟歌曲庫裡某一份相同時，仍會先問要不要覆蓋）。

歌曲庫只存在這個瀏覽器裡，不會上傳；換電腦或換瀏覽器就看不到。要長久保存，請用「檔案」的匯出，或在「儲存樂譜」框裡批次下載。

鍵作用前提
↑ ↓在選單的項目之間移動右鍵選單開著（捲軸、音符、小節尺、拍號、段落標記的選單都一樣）
← →調整那一項的數字（例如插入幾個小節、改成幾拍）右鍵選單裡、帶數字的項目
Enter／Space執行用方向鍵移到的那一項右鍵選單裡
Esc／Tab關閉選單右鍵選單裡

Enter下載焦點在「檔案」框匯出區的檔名欄
Enter確定焦點在段落標記的文字欄
