工作坊專用：工作坊是 MML Studio 裡的編輯器，但它在 Canonical 驗證流程之外。這一頁描述的是工作坊怎麼操作，在這裡做出來的譜一律是「工作坊編輯（未經 Studio 驗證）」——畫面左上角那個標籤就是在講這件事。要讓 Studio 檢查它，最後一節的送回 Studio 驗證才是那條路。

你手上有什麼

四種人走四條路，先確認你是哪一種：

你手上的東西走哪條路
什麼都沒有，想從零寫一首這一頁，從第一節開始往下讀
一份別人給你的 MML 文字（MML@…;）標題列的剪貼簿 → 貼上。它會取代所有分頁的內容。細節看剪貼簿那一節
一個檔案（.mid、.mml、.mmi、.musicxml、.mxl）標題列的檔案 → 選擇檔案，或把檔案拖進那個框。MIDI 的細節看 MIDI 轉 MML 教學
Studio 裡的一個專案標題列的從 Studio 開啟 → 選專案 → 在想要的 MML 來源那一列按開啟副本。開的是一份副本，會取代所有分頁；Studio 裡的專案不會被改動

這一頁只走第一條。走完你會得到一首七個音的短曲，加一條和弦軌，最後複製成一段貼得進遊戲空白樂譜的文字——重點不是那首曲子，是路上經過的每一個地方你都知道它在幹什麼。

還不知道 MML 是什麼？可以先讀 MML 教學，但不是必要的——這一頁不用你會寫任何一個字母。

介面五區

工作坊從上到下是五區，鋼琴捲軸與樂譜區之間夾著一條可以上下拖的分隔線（決定兩區各佔多高；選中它之後用方向鍵也能調，按著 Shift 走得比較快）：

這一區做什麼
標題列左邊是工作坊標誌與「工作坊編輯（未經 Studio 驗證）」標籤；從 Studio 開過副本時，旁邊還有一個「來源：Studio「…」」的小標示。右邊是進出口：← Studio（回到 Studio）、從 Studio 開啟、送回 Studio 驗證、剪貼簿（跟遊戲之間搬譜）、檔案（新增、儲存、匯入、匯出、清空）、設定、關於。有新版可用時會多一顆套用新版
工具列左半邊是播放：▶ 演奏、停止、捲軸同步、全曲／範圍、循環。右半邊是編輯：只選取（箭頭）、音符長度 1–32、縮放、復原／重做，以及速度／力度／移調／優化／合併五個功能。最右邊顯示現在是編輯中還是演奏中、正在編哪一軌，以及一行操作提示
鋼琴捲軸用滑鼠畫音符的地方。左邊是琴鍵（點得出聲，每個 C 那一列標著 o4C 這樣的名字），上面那條細的是小節尺
樂譜區上面一排是分頁，一個分頁＝一軌。分頁下面是樂器列（樂器、四顆小開關、字數），再下面是那一軌的 MML 文字
狀態列最下面一行：軌數（例如 軌 3 / 15）、音符數、速度、總長度、解析警告、暫存狀態（例如 已暫存 · 21:04）、引擎狀態

先把「軌」跟「角色」分清楚，後面全部靠它。

軌（分頁）是工作坊裡的一條單音線，有自己的樂器、自己的 MML 文字。一首曲子最少 3 軌、最多 15 軌，按分頁列最後的＋ 新增加一軌，按分頁上的 ✕ 移掉一軌（只剩 3 軌時不能再移）。

角色是遊戲那一邊的說法：遊戲的一份譜最多 6 個角色（基本 3 個、可擴充到 6 個），每個角色的 MML 文字上限 2,400 字（MOBILE_SYNTAX §2）。Canonical 把這六個角色叫做 Melody、Chord1–Chord5；其中 Melody + Chord1 + Chord2 稱為 Core3，是單人三和弦樂器的完整編曲目標（MASTER_RULES §5）。

工作坊的前 6 軌就是這 6 個角色，分頁名稱是主旋律、和弦1、和弦2、和弦3、和弦4、和弦5。第 7 軌以後叫輔助1到輔助9。

工作坊專用：輔助1–輔助9 只是工作坊裡的素材軌，可以拿來放暫時用不到的聲部、或當合併的來源。它們不會出現在複製出去的 MML 裡，也不會送回 Studio，WAV 匯出也只合成前 6 軌。

一、先聽一次

第一次打開看到的不是白紙，是一首現成的短曲：三軌（主旋律、和弦1、和弦2）、四小節、速度 120，樂器都是預設的 Lute。

要聽得到聲音，工作坊得先有音色庫——它自己不附音色。打開標題列的設定，在音色庫那一格二選一：

  • 選擇 .dls / .sf2 / .sf3：用你自己裝置上的音色庫檔案。它只存在這台裝置，而且跟 Studio 的試聽共用，之後打開工作坊會自動接回來
  • 使用遊戲風格音色：站方提供的遊戲風格音色（模擬，不是實機）。第一次使用時從本網站下載並核對 SHA-256，之後只存在這台裝置；不是每個網站都有提供，沒有的話它會直接告訴你

音色庫載好之前，▶ 演奏是按不下去的。載好之後什麼都別動，先按工具列左邊的 ▶ 演奏。

工作坊專用：不管用哪一種音色庫，工作坊的聲音都只是聆聽輔助：Mabinogi Mobile 樂器對到 GM 音色（Lute → GM 24 等）只是近似，遊戲風格音色也只是模擬。這裡聽到的不是遊戲的音色，也不是任何驗證的證據。

三件事會同時發生，值得各看一眼：

  • 鋼琴捲軸上有一條線從左往右掃過去——那是導播線，它走到哪就在響哪
  • 畫面自己往後翻頁。那是捲軸同步這顆在作用；播放中你自己去拖水平捲軸，它會自動關掉（因為你顯然想自己看別的地方），按一下可以再打開
  • 文字區的 MML 跟著反白，反白到哪就是正在唱哪一個字母（看的是你目前所在的那一軌）

按鈕會變成 ❚❚ 暫停，再按是 ▶ 繼續；停止則是回到頭。手不必離開鍵盤：Space 是演奏／暫停，播放中 ← → 前後一小節、↑ 回到開頭（或開始線）、↓ 停止（功能說明有完整的一組）。

想只聽中間一段：在小節尺上左鍵點一下設開始、右鍵開選單選「設定演奏結束線」，工具列的範圍會亮起來。按全曲會清掉那兩條線回到整首。旁邊的循環是播到結尾（或結束線）立刻從頭（或開始線）再來一次。

播放中兩邊都不能編輯。捲軸與文字區在播放時是唯讀的，這是刻意的——要改東西先按暫停或停止。暫停中可以改，改動會在按繼續之後生效。

二、清出一張白紙

要自己寫，得先把那首範例清掉。位置在標題列 → 檔案 → 最下面「清空」那一段 → 清空所有音符。

它會清掉全部 15 軌的樂譜文字，留下 3 個空白音軌；樂器選擇、檔名、調號都保留。按 Ctrl+Z 可以復原，所以放心按。

同一個對話框最上面還有一顆新增：它開一份全新的檔案，軌數、樂器與檔名全部回到預設（調號與換行設定保留），一樣可以用 Ctrl+Z 復原。只是想清掉音符的話，用「清空所有音符」就好。

想把範例叫回來，點左上角的「工作坊」標誌。那顆的意思是「重新開始」——它會把自動暫存清掉，再重新載入範例樂譜。它不會先問你，而且 Ctrl+Z 也救不回來，所以上面那個「清空所有音符」才是你在這一步該用的（那個復原得回來）。存進歌曲庫（檔案 → 儲存到…）的檔案不受影響。從主畫面以 app 模式開啟時，這個標誌不會顯示。

三、畫出七個音

我們畫小星星的開頭七個音：Do Do Sol Sol La La Sol。選它不是因為簡單，是因為你聽得出對錯——音階畫錯一個音沒人會發現，小星星錯一個當場就聽出來。

清空之後停在第一個分頁主旋律上，我們就畫在這裡。

用手機或平板看這一段？下面寫的是滑鼠與鍵盤的做法。手指的對應做法——輕觸畫音符、長按拿起來搬、選中之後用畫面底部的面板改長度與刪除——在手機與平板。對照著看就好，這一節其他內容通用。

先看工具列中間那一排。箭頭那一顆是只選取（快捷鍵 0，不會畫東西），右邊 1 到 32 六顆是音符長度：全音符、二分、四分、八分、十六分、三十二分（快捷鍵 1 到 6）。

按 3 選四分音符（或直接點那顆 4）。然後在捲軸上照這個順序左鍵點七下：

Do  Do  Sol Sol La  La  Sol

音高看左邊的琴鍵找——點琴鍵會發出那個音，聽到對的再往右邊那一格點下去。中央 Do 是琴鍵上標著 o4C 的那一列。

畫的時候可以用的四個動作，工具列右邊那行提示也寫著同一句話（「左鍵畫 · 拖曳搬動 · 拖右邊框改長度 · 右鍵開選單」）：

動作結果
左鍵點空白處放一個音，長度用你選的那一顆
拖曳音符搬動它（上下換音高、左右換位置）
拖音符的右邊框改長度
右鍵點音符開一個選單，最後一列是刪除音符（變回同長度的休止符，後面的音不會位移）

最後那個 Sol 想拉長成二分音符：拖它的右邊框往右拉。放開之前想取消就按 Esc。

畫完按 ▶ 演奏（或按 Space）。聽起來是小星星就對了。畫錯的音右鍵選刪除音符重畫，或按 Ctrl+Z。

Delete 也可以刪：先點選音符，再按 Delete。但它只在焦點不在文字區的時候是這個意思——在文字區裡 Delete 就是刪字。這件事在快捷鍵那一頁講得完整。

四、看一眼文字區

低頭看下面的文字區。你剛剛畫的七個音已經變成一行 MML 了，如果畫在 o4 那一個八度，它長這樣：

ccggaag2

前面沒有 l4 也沒有 o4，因為那就是工作坊的預設（四分音符、第 4 八度）。畫在別的八度的話，會多出 <、> 或 o 之類的八度記號，但形狀是一樣的。

捲軸與文字區是同一份資料的兩種樣子，不是兩個檔案。這句話有三個立刻用得到的後果：

  • 直接在文字區打字改 MML，捲軸馬上跟著變
  • 在文字區選一段文字，捲軸上那幾個音會跟著被選起來——反過來也一樣
  • 在捲軸上雙擊一個音（要在只選取模式下），文字區的游標會跳到那個音的位置。長譜上找音就靠這個

用捲軸編輯會重新產生整軌的 MML。音符內容一個都不會變，但你手寫的註解與手動排版會消失。所以習慣是：先用捲軸把音符弄對，最後才手動排版；不要反過來。想要自動排版的話，設定 → MML 格式化換行可以讓重新產生的文字每 1、2 或 4 小節換一行——換行只是排版，空白不佔遊戲字數。

五、加一條和弦軌

分頁列上現在有三個分頁：主旋律／和弦1／和弦2。剛剛畫的東西在主旋律裡。

點一下和弦1那個分頁，捲軸的焦點就換到那一軌（工具列右邊的「編輯中」後面也會變成和弦1），然後照同樣的方法畫幾個長音當伴奏——例如 Do Do Fa Do，每個用二分音符（按 2）。

畫的時候你會看到主旋律的音符還在，只是變成半透明；你正在編輯的那一軌是實心的。其他軌的音符都留在畫面上，是為了讓你對得準位置。在只選取模式下用滑鼠點一下別軌的半透明音符，會直接切到那一軌並選中它。

每個分頁底下的樂器列可以各自選樂器：下拉選單裡先列 Mabinogi Mobile 樂器（GM 近似）那 11 種（Lute、Mandolin、Chalumeau、Xylophone、Flute、Violin、Piano、Harp、Music Box、BassDrum、Cymbals），載入的音色庫有自己的音色時，下面還會多一組。樂器右邊有四顆小開關：靜音、只聽這一軌（兩個都只影響試聽，匯出照舊完整）、在捲軸上顯示這一軌、只看這一軌（兩個都只影響畫面）。

再按演奏，兩條線一起響。

一軌同時只能響一個音。和弦要拆到不同軌去（主旋律一個音、和弦1 一個、和弦2 一個）。[ceg] 這種寫法工作坊讀不懂，狀態列會標成「看不懂的字元」。詳見常見問題。

六、調速度

速度不要在文字區手打，用工具列的速度按鈕——它會把 t 寫到它該寫的地方，也會處理跨過速度變化的長音。

  1. 按速度，打開「速度/拍速」
  2. 設置位置選音軌開頭（曲子中途要換速度才選「選擇的音符前」，那要先選一個音，沒選的話那顆按不下去）
  3. 在速度（BPM）輸入數字或拉滑桿，範圍 32–255。旁邊的試聽會用固定的節拍型、以目前這一軌的樂器讓你聽速度本身；按住滑桿拖的時候也會自動響（演奏中、或音色庫還沒載好時不能試聽）
  4. 按執行。那個位置原本就有速度記號的話，對話框會說它會從幾改成幾，並多出一顆移除這個速度記號

寫進去之後，狀態列的速度會顯示新的值；曲中有換速度的話會顯示成 120 → 90 這樣的一串。還沒寫過任何速度時顯示「120 BPM（預設）」。

工作坊專用：速度工具把整首的速度圖只寫進主旋律，同時把其他各軌文字裡的 t 全部拿掉；別軌有音符跨過換速度的位置時，會把那個音切成兩段、用連結線接回去（聽起來一樣）。工作坊自己播放時，任何一軌的速度記號都套用到全部的軌，所以在這裡聽不出每一軌有沒有自己帶速度。

Canonical 的交付規則（MOBILE_SYNTAX §7）：T32–T255 是官方確認的範圍。交付時，每一個非空角色都要以同一個起始速度開頭；曲中有換速度時，每一個非空角色都要在相同的音樂位置帶著同一份完整的速度圖；完全空的角色保持空白，不為了驗證器補速度或休止符。這是為了同步安全訂的專案規則，不是官方說引擎技術上需要每個角色都帶速度；只有一個角色帶曲中換速度時遊戲會不會保持同步，目前是 PENDING_IN_GAME。

所以工作坊速度工具的結果（只有主旋律帶 t）不符合這條交付規則。Studio 的技術檢查會把「非空軌的速度圖彼此不同」標出來。

七、看字數

每個分頁的樂器列右邊都有一組數字，例如 7 音 · 8/2400 字。那是匯出後的字數，空白與換行（還有 /* */、// 註解）不計——所以你可以放心用換行分小節。

每個角色的 MML 文字上限是 2,400 字，這是官方確認的遊戲限制，六個角色各自算（MOBILE_SYNTAX §2、§9）。遊戲客戶端實際怎麼數字（跟程式裡的字串長度是否完全一致）還沒確認，是 PENDING_IN_GAME（MOBILE_SYNTAX §9）。

工作坊專用：樂器列上的數字是工作坊自己的算法。超過 2,400 字時那組數字會變紅（游標停上去會說超過幾字）；開著設定 → 語法上色時，超出的那一段文字也會加紅底。這些都只是提示，不會擋住你繼續編輯。

真的超了怎麼壓：工具列的優化，先選無損壓縮（一個音都不動，音符完全相同）。它不夠的話，下面的音長補滿、部分補滿、尾段收音三種不動任何音符的起始時間、也不改變節奏，但會改變音符長短，聲音會有差。詳見功能說明的優化那一節與常見問題。

八、複製 MML，貼進遊戲

最後一步。標題列 → 剪貼簿 → 複製。

那會把前 6 軌（主旋律到和弦5）複製成一段 MML@…; 的文字，角色之間用逗號隔開，整段貼進遊戲的空白樂譜。複製時會去掉空白與註解（工作坊的字數也不算空白；遊戲本身怎麼算字數尚未實機驗證，PENDING P1），能省的字會自動再做一次無損壓縮（音樂完全相同），結尾空著的角色不會留下多餘的逗號。完成時訊息列會寫「已複製 3 軌 · … 字元到剪貼簿」。

  • 瀏覽器不讓網頁直接寫剪貼簿的話，會跳出一個「複製 MML」的框，內容已經選好，按 Ctrl+C 帶走
  • 輔助軌有內容的話，訊息會告訴你哪幾軌沒有複製進去
  • 雙附點（..）會被改寫成等長、不用雙附點的寫法並告訴你；改寫不了的話那次不會複製，訊息列會說是哪一軌。瑪奇 PC／MabiIcco 那種非標準時值則照原文複製，並附上一句提醒
  • 字數超過 2,400 的角色照樣會被複製，而且這時不會再提醒你——複製前自己看一眼樂器列的字數有沒有變紅
  • 樂器選擇不在複製出去的文字裡（文字裡原本的 @ 數字也會拿掉）

要讓 Studio 檢查：送回 Studio 驗證

如果這首要走 Studio 的流程，按標題列的送回 Studio 驗證。對話框會列出要交出去的六軌 MML（遊戲讀的第 1–6 軌）和轉換時的注意事項；按送到 Studio 之後會回到 Studio。

在 Studio 那一邊，它會被當成衍生候選匯入，由 Studio 重新做技術驗證與各項審核。先前的審核與接受不會沿用，也不會因此變成 VALIDATED。工作坊本身不驗證任何東西——標題列那個「工作坊編輯（未經 Studio 驗證）」會一直在，就是這個意思。

你的東西留在這台裝置的瀏覽器裡：設定 → 自動存檔開著時，每次編輯後都會暫存，重新整理或關掉重開都接得回來（狀態列會寫「已接回上次的樂譜」）；想留很多首就用檔案 → 儲存到…（快捷鍵 Ctrl+S）存進歌曲庫。這些都不會上傳，換電腦或換瀏覽器就不見了，要長久保存請用檔案 → 匯出下載 .mid／.mml／.mmi，或在歌曲庫用批次下載。
