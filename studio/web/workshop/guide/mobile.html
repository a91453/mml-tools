用手指編曲：畫音符、搬音符、改長度

這一頁給誰

判準是你用手指，不是螢幕多小。平板橫著放很寬，一樣是這一套；手機直放也是這一套。工作坊看的是你最後一次按下去用的是手指還是滑鼠，所以同一台觸控筆電，用手指點就是這一頁的行為，改用滑鼠就回到桌機的行為。反過來說，把桌機視窗拉得很扁雖然會讓版面收起來，但那時你手上還是滑鼠，這一頁對你沒有用——那件事在窄螢幕與手機。

手機上能做的事跟桌機一樣多：畫音符、搬音符、改長度、加附點、換樂器、插刪小節、匯入匯出，全都在。長譜在桌機上會快一些，但短譜、改幾個音、在外面臨時想到什麼要調，手機完全夠用。

還沒摸過工作坊的話，先走一次編輯器入門——那一頁是從打開工作坊到把譜複製出來的完整路線。它的第三節用的是滑鼠說法，對照這一頁看就好，其他內容通用。

單指：輕觸、拖曳、長按

一根手指有三種下法，而它們的意思看你按在哪裡、以及工具列現在是哪個模式（只選取還是拿著某個音符長度，見捲軸工具列）：

拖曳＝平移畫面（多選亮著時＝框住一片）

幾個值得先知道的：

  • 按下去不會馬上選。手指同時是游標也是點擊，所以工作坊會先等一下：移動超過一點點就當成你要捲畫面，按住不動約 0.4 秒就當成長按，兩個都不是才在放開時算成輕觸。想捲畫面的時候不會順手改掉選取。
  • 用手指輕觸畫音符時，落點會對齊你拿著的那個長度的格子（最粗對齊到四分音符），不容易點歪。
  • 長按搬音符時拖到畫面邊緣，捲軸會自己捲。要搬去很遠的地方不必先放開。
  • 插入／刪除小節要在「只選取」模式的空白處長按。拿著音符長度的時候，長按那條路讓給了預覽畫音符，所以叫不出選單——切回只選取就有了。選單裡有什麼在右鍵選單（空白處）。
  • 附點：拿著音符長度時，長度按鈕旁邊那個音符圖示就是附點開關（鍵盤上的 .），按一下，接下來畫的音都是附點（長度 ×1.5）。

雙指：平移與縮放

兩根手指放上去之後，先動的那一種贏：

你做的動作結果
兩指一起移動平移畫面
左右張開或捏合改格子寬度——看多幾小節，或把某一段拉開來對位
上下張開或捏合改列高——看多幾個八度，或把音高拉開來看清楚

兩軸是分開判斷的，所以手指斜斜地擺著做水平張開也認得出來——它看的是你真正在做的事，跟你把手擺成什麼角度無關。

在手機的窄版面上，工具列的縮放按鈕是收起來的，縮放就靠這兩個手勢。

選中之後：操作面板

用手指選中一個音（或一組），畫面底部會浮出一塊面板（狀態列顯示著的時候，它貼在狀態列上方）。它是手機上微調音符的地方，也是音符選單與刪除最順手的入口。播放中、或這一軌不能用捲軸編輯的時候，它不會出現。

面板的樣子，由上而下：

  • 最上面一行是警告行——只在你正在做的搬動或改長度會蓋掉、截短別的音時出現
  • 左邊是四顆尖端朝內的方向鍵
  • 右邊上排是多選與☰ 選單兩顆鍵
  • 右邊中間是一根橫長形的長度微調桿，中間有一顆圓鈕
  • 右邊下排是取消選擇與紅色的刪除

面板出現的時候，下面的 MML 文字區會暫時退場（分頁與樂器列還在），取消選擇就回來。那是刻意的：這時候你要對照的只有兩樣東西——捲軸上那個音，跟手上的按鍵——把文字區收掉，那兩樣才靠得近。文字沒有不見，也沒有被改。

方向鍵：搬音符

左邊那組是四顆方向鍵。按哪一邊，音符就往哪一邊走——左右換位置、上下換音高，一按走一步。

上下左右
一個半音六十四分音符

按住不放會連續走（按下去先走一步，按住約 0.3 秒後開始連續走）。

多選的時候，方向鍵一次搬整組，它們之間的相對關係不變。

停手大約 0.4 秒才真的寫進去。中間都只是預覽，所以連按十下、或按住三秒，復原都只要按一次就全部收回來——那是一整段調整，不是十件事。

要搬去很遠的地方就長按把音符拿起來拖。這兩件事刻意分工：拖曳負責跨越距離，方向鍵負責最後那幾格——手指拖不準的那一段，正是方向鍵存在的理由。

長度微調桿：改長度

右邊那根橫長形的桿子，只能左右推：往右變長、往左變短，推得越遠變得越快，放在中間附近則不動。它推起來刻意偏慢，因為長度推過頭會影響到後面那個音（變長會把後面的音截短甚至蓋掉）。落點細到六十四分音符，所以慢不等於粗。推的時候捲軸上會出現一個十字游標，那是你目前推到的位置——兩個落點之間只有幾個像素，沒有它會看起來像桿子失靈。手指放開桿子就寫進去。

會蓋掉東西的時候，面板最上面那一行會告訴你會刪掉幾個音、會截短幾個音。不想要就推回來，那一行會消失。用方向鍵搬音符時，這一行也一樣會提醒你。

多選的時候長度微調桿會變暗，推不動。一組長度不一樣的音沒辦法一起改長度，這條規則桌機也一樣（用滑鼠拖右邊框也只改得了一個音），不是手機少了什麼。要改就一個一個選。

四顆鍵

鍵做什麼
多選按亮它，接下來輕觸音符是加進選取而不是換一個；輕觸已經選起來的音則是把它抽掉。再按一次這顆鍵就關掉。選好之後可以一次搬、一次刪，或一次套用選單裡的功能。亮著而且在只選取模式時，還可以在空白處拖曳框住一片，框到的音全部加進來，本來選著的不會被框掉——那時單指拖曳讓給了框選，要捲畫面就用兩根手指，或者從音符上起手拖。警告行會提醒你「拖曳空白處＝框選 · 雙指捲動」
☰ 選單叫出音符上的選單——演奏開始／結束設在音符前後、選擇前方／後方所有音符、加上附點、設定力度、貼上、複製、剪下、刪除音符等等，跟桌機右鍵點音符是同一個選單，內容在右鍵選單（音符上）。選單就開在這顆鍵上面
取消選擇放掉選取，同時把多選關掉。面板跟著收起來，文字區回來。在只選取模式下手指誤觸到空白處不會關掉面板，要收起它就按這一顆
刪除刪掉選起來的音（多選時一次刪整組）。按下去就刪，不會再問一次——紅色已經把話講完了，而且復原收得回來

下面那一排刻意跟上面隔開：那兩顆是離開跟毀掉，上面兩排是調整，手指不該在它們之間滑錯。

方向鍵與長度微調桿不會同時作用。一邊搬位置一邊改長度不是一個有意義的動作：推著長度桿時按方向鍵，會先把長度寫進去再開始搬；方向鍵搬過還沒寫進去的那 0.4 秒裡，長度桿推不動。

打字與畫面

四顆顯示開關

畫面窄的時候（寬度 528 像素以下，或高度 480 像素以下，例如手機橫放），標題列上會多出四顆圖示開關（桌機的一般視窗看不到）：

開關關掉之後
顯示工具列只選取、音符長度、復原重做、速度力度移調優化合併、編輯中那一段收起來；左邊的演奏、停止、捲軸同步、範圍、循環留著
顯示鋼琴捲軸只剩文字，適合專心打 MML
顯示編輯器MML 文字收起來（分頁與樂器列還在），適合專心畫音符
顯示狀態列最下面那條狀態文字收起來

亮著代表現在看得到。手機上垂直空間最稀缺，關掉一區，剩下的會把空間吃掉——這四顆是你在小螢幕上最常用的東西。它們不會被記住，重新載入頁面後四顆都會回到亮著。

軟鍵盤頂上來的時候

手指點進 MML 文字區，系統鍵盤會蓋掉半個畫面。在窄版面時，工作坊會自己讓出高度：只要游標在文字區裡，工具列的編輯那一段、樂器列、狀態列就暫時收起來，捲軸留著——因為打字的時候你正要看捲軸上的結果。離開文字區，那三樣就回來。

那幾顆開關會亮著，但東西不在畫面上，這是刻意的。開關反映的永遠是你自己按過的選擇，不會被打字的來去改掉——所以你手動關掉工具列之後打字再離開，它不會被「好心」放回來；打字中按那顆開關，離開文字區之後也照你按的結果走。

還有一件事：點分頁不會彈出鍵盤。在小螢幕上點另一個分頁通常是想看那一軌的音符，不是要打字——所以切分頁、按＋ 新增加一軌，焦點都是放在捲軸上，不會把游標塞進文字區。要打字就自己點一下文字區。

裝成 app 與離線使用

工作坊是 MML Studio 網站（Studio Web）裡的一頁，能安裝的是整個 Studio Web。裝到主畫面之後開起來沒有網址欄，跟一般 app 一樣；它開啟的是 Studio 的主頁面，從 Studio 側欄的工作坊 · MML 編輯器進來。

要從 Studio 的主頁面安裝。Android 的 Chrome 通常會自己冒出安裝提示；沒看到的話從瀏覽器選單找「安裝應用程式」或「加到主畫面」。桌機的 Chrome 與 Edge 是在網址列右側出現一顆安裝鈕。iPhone 與 iPad 沒有自動提示，要自己來：用 Safari 開 Studio，點「分享」→「加入主畫面」（Studio 側欄的加入主畫面也寫著這一步）。

第一次完整載入之後就能離線開啟。Studio Web 有一個 Service Worker，會把網站的頁面與程式（工作坊也在內）留在這台裝置上，沒有網路的時候照樣打得開、打得動。網站有新版時，它會先在背景下載好，工作坊標題列會多出套用新版——按了才會先寫出自動暫存再重新載入；其他開著的 Studio 分頁之後也要重新載入。

離線要有聲音，音色庫得先留在裝置上。網站本身不附音色庫：

  • 你自己的 .dls／.sf2／.sf3：在設定 → 音色庫選過一次，它就存在這個瀏覽器裡（與 Studio 的試聽共用），之後離線也用得到
  • 遊戲風格音色：第一次按使用遊戲風格音色時從本網站下載（約 15.3 MB）並核對 SHA-256，之後存在這台裝置上。所以要在有網路的時候先用過一次，離線時才有它

工作坊專用：Studio 自己的試聽另有一個免費的預設音色（通用 GM 音色的子集），第一次需要時從 MuseScore 官方來源下載；工作坊不會用它，也不會自己去下載任何音色。沒有選過音色庫的話，工作坊打得開、編得動，但▶ 演奏按不下去。不管哪一種音色，聽到的都只是近似或模擬，不是遊戲的音色。

瀏覽器在空間不足時可能把網站資料清掉（iPhone 與 iPad 上比較容易遇到），那時離線的頁面、音色庫、自動暫存與歌曲庫都可能不見。Studio 側欄有一顆保留離線資料，可以請瀏覽器保留本機資料，但瀏覽器不一定答應；重要的譜請用檔案 → 匯出或歌曲庫的批次下載存一份到本機。

另外，從主畫面以 app 模式開啟時，工作坊左上角的「工作坊」標誌（按了會清掉暫存、重新載入範例）不會顯示。

其餘跟桌機一樣

剩下的東西手機上都在，用法也一樣，只是收在標題列最右邊那顆選單（☰）裡：← Studio、從 Studio 開啟、送回 Studio 驗證、剪貼簿、檔案（新增／儲存／匯入／匯出／清空）、設定、關於，有新版時還有套用新版。工具列的速度／力度／移調／優化／合併、樂器列、分頁、狀態列也都跟桌機一樣。

手機上匯出要注意兩件事：匯出 WAV 與 MP4影片製作都在這台裝置上合成，曲子長的時候手機可能記憶體不足，那時改用電腦或把曲子縮短；做影片需要瀏覽器支援 WebCodecs（Chrome、Edge 或 Safari 16.4 以上），製作期間請讓分頁留在前景，也不要讓螢幕休眠。

那些都寫在功能說明與快捷鍵。版面在窄畫面上怎麼收，在窄螢幕與手機。
